# Googleの自動ログイン設定（中継スクリプト）

Daily Flow を開いた時点で、Googleカレンダーの予定と Google ToDo を自動で読み込むための設定です。
自分のGoogleアカウントで動く小さなスクリプト（Google Apps Script）を一度だけ用意します。
設定したあとは、アプリでGoogleにログインする必要はありません。スマホとPCの両方で使えます（端末間同期でURLと合言葉も共有されます）。

所要時間：10分ほど（PCでの作業がおすすめです）

---

## 1. アプリで合言葉を作る

1. Daily Flow の右上の ⚙（設定）を開く
2. 「Googleカレンダー・ToDo連携（自動ログイン）」の **①合言葉** で「作る」→「コピー」

## 2. スクリプトを作る

1. https://script.google.com を開き、Daily Flow で使う Google アカウントでログイン
2. 左上の「新しいプロジェクト」
3. 上の「無題のプロジェクト」を押して、名前を `Daily Flow 連携` にする
4. `コード.gs` の中身をすべて消し、このフォルダの [`Code.gs`](./Code.gs) の中身をすべて貼り付ける
5. 先頭近くの次の行の `ここに合言葉を貼り付け` を、手順1でコピーした合言葉に置き換える

   ```js
   const SECRET = 'ここに合言葉を貼り付け';
   ```

6. 左の「サービス」の **＋** →「Google Tasks API」を選んで「追加」（ID は `Tasks` のまま）
7. 💾（保存）を押す

## 3. 権限を許可する（初回のみ）

1. 上の関数の選択欄で `testAuthorize` を選び、「実行」
2. 「承認が必要です」→「権限を確認」→ 自分のアカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら、「詳細」→「Daily Flow 連携（安全ではないページ）に移動」
   - 自分で作った自分専用のスクリプトなので問題ありません
4. 「許可」を押す
5. 下の実行ログに自分のメールアドレス、カレンダー名、`Tasks OK` が出れば成功

## 4. Webアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車 ⚙ →「ウェブアプリ」
3. 次のように設定して「デプロイ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）をコピー

> 「全員」にしても、合言葉を知らない人は何も読めません。合言葉は他人に教えないでください。

## 5. アプリに登録する

1. Daily Flow の設定に戻り、**②中継スクリプトのURL** に貼り付け
2. 「保存して接続テスト」
3. 「✓ 自動ログイン設定済み（メールアドレス）」と出れば完了です

---

## うまくいかないとき

| 表示 | 対処 |
|---|---|
| 合言葉が一致しません | `Code.gs` の `SECRET` とアプリの合言葉が同じか確認し、保存してから「デプロイ」→「デプロイを管理」→ ✏ →「バージョン：新バージョン」で更新 |
| 応答を読めません | デプロイの「アクセスできるユーザー」が「全員」になっているか確認 |
| Google Tasks API サービスが追加されていません | 手順2-6 を行い、「デプロイを管理」から新バージョンで更新 |

`Code.gs` を書き換えたときは、必ず「デプロイを管理」→ ✏ →「新バージョン」で更新してください（URLは変わりません）。
