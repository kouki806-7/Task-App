# Googleの自動ログイン設定（中継スクリプト）

Daily Flow を開いた時点で、Googleカレンダーの予定と Google ToDo を自動で読み込むための設定です。
自分のGoogleアカウントで動く小さなスクリプト（Google Apps Script）を一度だけ用意します。
設定したあとは、アプリでGoogleにログインする必要はありません。スマホとPCの両方で使えます（端末間同期でURLと合言葉も共有されます）。

所要時間：10分ほど（PCでの作業がおすすめです）

**コードは書き換えずに貼り付けるだけです。** 合言葉はスクリプトが自動で作ります。

---

## 1. スクリプトを作る

1. https://script.google.com を開き、Daily Flow で使う Google アカウントでログイン
   - 前に作った「Daily Flow 連携」がある場合は、それを開いて使います
2. 「新しいプロジェクト」を作り、名前を `Daily Flow 連携` にする
3. `コード.gs` の中身をすべて消し、このフォルダの [`Code.gs`](./Code.gs) の中身をすべて貼り付ける（**書き換えは不要**）
4. 左の「サービス」の **＋** →「Google Tasks API」を選んで「追加」（すでに追加済みなら不要）
5. 💾（保存）

## 2. setup を実行して合言葉を表示する

1. 上の関数の選択欄（「デバッグ」の右）で **`setup`** を選び、「実行」
2. 初回は権限の確認が出ます
   - 「権限を確認」→ 自分のアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「Daily Flow 連携（安全ではないページ）に移動」（自分専用のスクリプトなので問題ありません）
   - 「許可」
3. 下の「実行ログ」に次のように出ます

   ```
   合言葉: 3f9c0a1b2d4e5f60718293ab
   ```

   `合言葉: ` の後ろの文字列が合言葉です（行ごとコピーしても大丈夫です）

## 3. ウェブアプリとして公開する

- **初めての場合**：右上「デプロイ」→「新しいデプロイ」→ 歯車 ⚙ →「ウェブアプリ」
  - 次のユーザーとして実行：**自分**
  - アクセスできるユーザー：**全員**
  - 「デプロイ」を押し、表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）をコピー
- **前にデプロイ済みの場合**：右上「デプロイ」→「デプロイを管理」→ ✏ →「バージョン」を **新バージョン** →「デプロイ」（URLはそのまま）

> 「全員」にしても、合言葉を知らない人は何も読めません。合言葉は他人に教えないでください。

## 4. アプリに登録する

1. Daily Flow の ⚙（設定）→「Googleカレンダー・ToDo連携（自動ログイン）」
2. **①URL** にウェブアプリのURL、**②合言葉** に手順2の合言葉を貼り付け
3. 「保存して接続テスト」
4. 「✓ 自動ログイン設定済み（メールアドレス）」と出れば完了です

---

## うまくいかないとき

設定画面の「ブラウザで確認」を押すと、スクリプトの応答が別タブで開きます。

| 表示 | 意味と対処 |
|---|---|
| `{"ok":true,"email":"…"}` | 正常です。「保存して接続テスト」を押してください |
| `{"ok":false,"error":"secret_not_set"}` | まだ `setup` を実行していません（手順2） |
| `{"ok":false,"error":"unauthorized"}` | 合言葉が違います。`setup` をもう一度実行し、実行ログの合言葉を貼り直してください。それでも変わらなければ、公開中のスクリプトが古いままです（手順3の「新バージョン」で更新） |
| 「ファイルは存在しません」 | URLが違います。デプロイ画面のURLをコピーし直してください |
| Googleのログイン画面が出る | 「アクセスできるユーザー」が「全員」になっていません |

合言葉を作り直したいときは、関数の選択欄で `resetSecret` を実行し、新しい合言葉をアプリに貼り直してください（デプロイし直す必要はありません）。
