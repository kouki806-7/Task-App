    📅 追加Googleカレンダー設定

    「Google同期」で一括取得したい追加カレンダーのIDを登録します。
    カレンダーID は通常メールアドレス形式（例: friend@gmail.com）です。
    ※ そのカレンダーを共有してもらうか、同一Googleアカウント内のカレンダーが対象です。

    登録後は「Google同期」ボタンを押すと全カレンダーをまとめて取得します。

    Google Calendar API 連携

    スケジュール画面で「Google同期」を行うための設定です。Google Cloudから取得したキーを入力してください。

    保存しました！

    ✨ AI設定

    AI機能（計画提案・タスク分解）に使用するLLMを選択できます。
    未設定でもヒューリスティック（ルールベース）で動作します。

    例: Ollama = http://localhost:11434　LM Studio = http://localhost:1234

    ⚠️ CORS設定が必要です
    ブラウザからローカルLLMに接続するには、サーバ側でCORS許可が必要です。
    Ollama: 環境変数 OLLAMA_ORIGINS=* を設定してから ollama serve
    LM Studio: 「Local Server」タブで「Enable CORS」をオン
